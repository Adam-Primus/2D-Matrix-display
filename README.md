# README
## Summary of the Project
This project is a *2-dimensional LED dot matrix display*. It has 5 horizontal Rows and 6 vertical colums of arranged LEDs[I prefered White LEDs] i.e. **5 x 6 Matrix**. It uses a microcontroller which I am using the *Doit ESP32 Devkit V1* microcontroller to control the rows and colums and using *VSc* to program the microcontroller

I am a beginner at electronic and want to learn new things and upgrade my experience. This project was  actually recomended to me by my friend that this project will inhance my working experience with microcontrollers, my way of soldering, and of course improve my experience of electronic.
